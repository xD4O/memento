MEMENTO

A live journal you talk to — and it remembers everything.

This is no longer a plan — it runs today on the operator's own hardware. Record video log entries or speak with a full-duplex live agent that listens, responds in real time, asks progressively deeper questions, and builds rapport across sessions. Every entry is transcribed, indexed, cataloged, and reflected upon; the journal answers questions, compiles your days and weeks, sends messages through time, and is learning to see. The final form — a photoreal human presence — waits on the research frontier.

SEC 01

North Star

The product is the memory plus the conversation. The avatar is presentation. Every phase below must end with something used daily — habit before technology.

SEC 02

Design Principles

Type-1 decisions
R-01

Raw media is the source of truth

Original video/audio files are immutable and sacred. Transcripts, embeddings, flags, and summaries are derived data — always rebuildable. This makes almost every other technical choice reversible.

R-02

Provider-as-driver

The live voice agent and the avatar renderer sit behind adapters in a session gateway. Cloud APIs today, local models tomorrow, end-to-end audio-video foundation models eventually — without touching the journal core.

R-03

Single-user first, multi-tenant-shaped

Every table has a user id, every storage path is user-prefixed, auth is an interface. No multi-tenant features, but no single-user assumptions baked into the data.

R-04

Privacy gradient

Transcripts, embeddings, index, and media never leave the DGX. Only the live voice stream transits the cloud provider, in zero-retention mode. The full-local variant is the permanent escape hatch.

R-05

Habit before technology

Each phase exits only when its deliverable is being used every day. A perfect avatar on an unused journal is a failure.

SEC 05

Prompting Engine

core differentiator — build

A question ladder with rapport state, not a static prompt. The agent earns depth from engagement signals — answer length, disclosure, explicit invitation — and always de-escalates on deflection.

L0Check-in“How was the day? What's on your mind?”
L1Concrete“What happened with the demo?”
L2Reflective“Third time this month you've mentioned feeling stretched — what's driving that?”
L3Depth — earnedValues, meaning, identity — only after rapport signals.

Threads surface open loops from prior entries naturally, never as an interrogation. The agent never fabricates memories — every reference to the past carries a retrievable citation (entry + timestamp) the UI can jump to. Session end: the agent writes a summary, updates threads, and proposes flags for the user to confirm or edit.

Guardrail

A journaling companion, not a therapist. Scope limits and crisis-resource deflection in the system prompt; the agent's model of you (profile, threads) fully inspectable.

SEC 08

Deployment Variants

Full-Local privacy-max

Local speech-to-speech driver on the DGX: an open full-duplex model (Moshi-class / Qwen-Omni-class) or a cascaded VAD → whisper → LLM → streaming-TTS pipeline. Expect 0.8–1.5 s turns and weaker barge-in today. Everything else identical.

Trigger ▸ open S2S crosses “pleasant daily conversation,” or privacy stance hardens.

Hybrid chosen

Cloud only for the live voice loop, zero-retention mode. All memory, media, and indexing local on the DGX. Best conversation quality available today with the smallest privacy surface.

Status ▸ the build target for phases 0–4, as architected in SEC 03.

Full-Cloud product shape

Vercel + Neon/Supabase + R2 media + cloud whisper + realtime API + interactive-avatar API. Fastest to multi-user product, lowest ops; intimate data lives with vendors — requires real consent UX and retention policy.

Trigger ▸ “product later” activates. Adapter swaps, not a rewrite.

SEC 09

Security & Privacy

  • Tailscale-only until Phase 2 auth hardening; STRIDE on gateway + API before public exposure.
  • API keys server-side only; client receives ephemeral WebRTC session tokens.
  • Realtime API zero-retention / no-training flags on; provider config logged in repo.
  • Nightly encrypted backup of MinIO + Postgres to second disk / offsite — raw media is irreplaceable (P0, Phase 1).
  • Soft-delete everywhere; hard-delete is a deliberate two-step action.
  • Profile and threads — the agent's model of you — always visible and editable.
